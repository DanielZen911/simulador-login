# Simulador de Inicio de Sesión

Este proyecto es un script básico de JavaScript que simula un sistema de login o inicio de sesión. Fue desarrollado como un ejercicio práctico para aplicar conceptos de lógica de programación como el uso de variables, condicionales, ciclos (`while`) y funciones modulares.

## Tecnologías Utilizadas

* HTML5 

* JavaScript 

## Estructura de Archivos

* `index.html`: Archivo principal que sirve como punto de entrada y conecta la lógica.

* `login.js`: Archivo que contiene toda la lógica modular del inicio de sesión.

## Cómo ejecutar el proyecto

1. Asegúrate de tener los archivos `index.html` y `login.js` guardados en la misma carpeta.

2. Abre el archivo `index.html` en tu navegador web preferido (haciendo doble clic sobre el archivo o utilizando la extensión *Live Server* en Visual Studio Code).

3. Responde a los cuadros de diálogo que aparecerán automáticamente en la pantalla.
